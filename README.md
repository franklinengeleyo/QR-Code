# React Counter App

A simple counter application built with React to practise the fundamentals of React development.

## Features
- Increment the counter.
- Decrement the counter.
- Reset the counter to zero.

## Technologies
- React
- JavaScript
- CSS

## Getting Started
```bash
npm install
npm run dev
```

## Purpose
My first React project, built to practise components, state management using `useState`, and event handling.
